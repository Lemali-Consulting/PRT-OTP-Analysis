## Out of Scope

1. **Analysis 31**: The FINDINGS.md discussion section (lines 30-41) provides an extensive and well-reasoned caveat that the OTP gain estimate is likely overstated because buses already skip empty stops operationally. This is a valuable qualitative correction that partially mitigates the quantitative issues flagged above. The self-critique is unusually thorough for an analysis file.

2. **Analysis 32**: FINDINGS.md line 36 notes "Light rail shows 100% coverage but only 1 stop appears in the data." With n=1, the 100% coverage rate for Light Rail is not meaningful. The code does not flag or caveat this in the chart, where "Light Rail: 100%" appears alongside modes with hundreds or thousands of stops. This is not a checklist category issue but could be visually misleading.

3. **Analysis 35**: The system-wide on/off ratio of 1.003 (line 185: `total_ons / total_offs`) is a useful sanity check — boardings should approximately equal alightings for a closed transit system. The slight surplus could reflect transfers or data collection methodology. This is an interesting diagnostic not discussed in FINDINGS.md.

4. **Analysis 31**: The 400m walk-distance threshold is stated as a constant (line 17) but not justified empirically. The choice of 400m vs 200m, 300m, or 500m substantially affects the number of candidates. A sensitivity analysis varying this threshold would strengthen the findings. FINDINGS.md line 43 acknowledges this in passing ("starting with stops below 1 rider/day that have a neighbor within 200 m") but no formal sensitivity analysis is performed.
