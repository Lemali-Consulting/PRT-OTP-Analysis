# PRT Stop-Signal Classification

Authoritative bus-stop signal classification provided by Samuel Buckley (Pittsburgh
Regional Transit), June 2026. Each of the 6,306 bus stops carries a `mode` tag
identifying whether it sits at a signalized intersection and, if so, whether it is
near-side or far-side of the signal. Ingested into the `stop_signals` table by
`pipeline/15_stop_signals/`.
